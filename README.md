Цель работы

Изучить механизмы управления пользователями, мониторинга файлов и процессов, повышения привилегий set-UID, Linux capabilities и разграничения административных полномочий с помощью sudo.

Раздел 1. Создание пользователя

Создан пользователь user1 с UID 1234, основной группой students и домашним каталогом /home/user1.

Настроена обязательная смена пароля каждые 90 дней.

Использованные команды:

sudo groupadd students
sudo useradd -m -u 1234 -g students -s /bin/bash user1
sudo passwd user1
sudo chage -M 90 user1

Результат: пользователь создан, пароль установлен, права домашнего каталога — 700.

Раздел 2. Мониторинг файлов и процессов

Проведён поиск файлов с установленным битом set-UID.

sudo find / -type f -perm -4000 -print

Выполнен мониторинг процессов с эффективным UID 0 и реальным UID обычного пользователя.

Обнаружен процесс fusermount3 с RUID 1000 и EUID 0.

Доказательства: suid-files.out, privileged-processes.out.

Раздел 3. Изучение механизма set-UID

Создана отдельная копия стандартной утилиты cat по пути /opt/mephi-lab/cat-suid.

Для неё назначен владелец root и установлены права 4755.

sudo chown root:root /opt/mephi-lab/cat-suid
sudo chmod 4755 /opt/mephi-lab/cat-suid

Пользователь user1 успешно прочитал защищённый файл /root/mephi-setuid-test.txt, недоступный при обычном запуске cat.

Результат: механизм set-UID позволяет программе выполнять операцию с эффективными правами владельца.

Доказательства: stat.out, setuid-result.out.

Раздел 4. Изучение Linux capabilities

Для копии утилиты chown настроена привилегия CAP_CHOWN.

sudo setcap cap_chown+ep /opt/mephi-lab/chown-cap

Обычная команда chown, запущенная пользователем user1, не смогла изменить владельца файла на root.

Копия chown-cap успешно выполнила аналогичную операцию благодаря установленной capability.

Результат: отдельные привилегированные операции можно разрешать без предоставления программе полного набора полномочий root.

Доказательства: getcap.out, capabilities-result.out.

Раздел 5. Настройка sudo

Для пользователя user1 создано отдельное правило в /etc/sudoers.d/mephi-user1:

user1 ALL=(root) /usr/bin/date -s *

Конфигурация проверена командой sudo visudo -c.

Пользователь user1 успешно выполнил установку системного времени через sudo.

Доказательства: sudoers-rule.out, sudo-result.out.
